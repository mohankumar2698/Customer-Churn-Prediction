# Customer Churn Prediction

## Objective

Predict customers likely to leave a telecom company.

## Techniques Used

- EDA
- Feature Engineering
- Random Forest Classification
- Model Evaluation

## Results

Accuracy: 95%

## Key Findings

- Short tenure customers churn more.
- High support tickets increase churn risk.
- Long-term contracts reduce churn.

## Conclusion

Random Forest successfully predicts customer churn and can help improve customer retention strategies.
