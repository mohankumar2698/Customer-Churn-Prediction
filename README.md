# Customer Churn Prediction System

## Overview

A machine learning project that predicts whether a customer is likely to churn based on account information.

## Features

- Data Cleaning
- Exploratory Data Analysis
- Machine Learning
- Random Forest Model
- Streamlit Dashboard
- Model Serialization

## Technologies

- Python
- Pandas
- Scikit-Learn
- Streamlit
- Matplotlib
- Seaborn

## Run

Train Model

```bash
python src/train.py
```

Run Dashboard

```bash
streamlit run dashboard/app.py
```

## Results

- Churn Prediction
- Feature Importance
- Customer Insights
